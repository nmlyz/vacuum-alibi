vacuum-alibi is a tiny program that writes one line to a file: the excuse a robot vacuum gives for missing a spot, in the machine's own deadpan voice — a specific detail up front, the punch at the end, and nothing else.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
